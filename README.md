# PragnyX — CA Firm Management Website

A full-stack MERN application for a Chartered Accountant firm, built as the PragnyX Full Stack Developer technical assignment.

## Assignment scope

The application will cover the requirements in the supplied assignment:

- Public website: Home, About Us, Services, Service Details, and Contact Us.
- Eight CA services: Income Tax Filing, GST Registration and Filing, Company Registration, Accounting and Bookkeeping, Tax Planning and Consultancy, Auditing Services, Financial Advisory, and Business Compliance.
- Authentication: registration, login, logout, password hashing, JWT authentication, protected routes, and profile management.
- Client dashboard: profile, service exploration and requests, inquiry history, consultation bookings, and booking status.
- Consultation booking: client details, service, preferred date/time, message, validation, and admin status management.
- Admin dashboard: statistics, client management, service CRUD, inquiry management, and booking management with role-based authorization.

## Technology

- Frontend: React.js, React Router, HTML5, CSS3, JavaScript, Axios (or Fetch).
- Backend: Node.js, Express.js, REST APIs, JWT, bcrypt, and input validation.
- Database: MongoDB with Mongoose.
- Tooling: Git/GitHub, Postman, environment variables, and deployment platform.
