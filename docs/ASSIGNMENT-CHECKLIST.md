# PragnyX Assignment Checklist

This checklist mirrors the supplied seven-page assignment.

## Modules

- [ ] Home page: logo/navigation, hero, about, services, why choose us, testimonials, contact details, social footer.
- [ ] Services page: all eight specified CA services; title, description, image/icon, and details page for each.
- [ ] Authentication: registration, login, bcrypt hashing, JWT, logout, protected routes, profile management.
- [ ] Client dashboard: profile, services, service requests, inquiry history, consultation booking, booking status.
- [ ] Consultation booking: name, email, phone, service, preferred date/time, additional message; MongoDB persistence; reject invalid/past dates; status display and admin actions.
- [ ] Admin dashboard: admin authentication, statistics, client totals, inquiry totals, booking totals, service CRUD, client list, inquiry management, booking management, status updates, role-based route protection.
- [ ] Contact/inquiry: full name, email, phone, subject, message; MongoDB persistence and admin management.

## Required pages

## Technical requirements

- [ ] React, HTML5, CSS3, JavaScript, React Router, Axios/Fetch, responsive UI.
- [ ] Node.js, Express.js, REST APIs, JWT, bcrypt, input validation, error handling.
- [ ] MongoDB, Mongoose, appropriate schemas, data validation.
- [ ] Git/GitHub, Postman testing, environment variables, deployment.

## Final submission

- [ ] Complete working website
- [ ] GitHub repository
- [ ] Live website URL
- [ ] Backend API URL
- [ ] README setup instructions
- [ ] Database schema explanation
- [ ] Screenshots of major modules
- [ ] Admin and client test login credentials
